# Graj i Zbieraj

Darmowa, przeglądarkowa mini-gra w języku polskim. Gracz łapie gwiazdki, zdobywa wirtualne punkty i odblokowuje nagrody wewnątrz gry.

## Uruchomienie lokalne
Otwórz plik `index.html` w przeglądarce.

## Publikacja przez GitHub Pages
1. Otwórz repozytorium `Graj-i-zarabiaj` na GitHubie.
2. Wybierz **Add file → Upload files**.
3. Rozpakuj paczkę i wgraj pliki `index.html` oraz `README.md` do katalogu głównego repozytorium.
4. Zatwierdź zmiany przyciskiem **Commit changes**.
5. Otwórz **Settings → Pages**.
6. W sekcji **Build and deployment** wybierz **Deploy from a branch**, gałąź `main` i folder `/ (root)`, a następnie zapisz.
7. Po publikacji GitHub pokaże adres strony w sekcji Pages.

## Ograniczenia tej wersji
Punkty i odblokowane dodatki są zapisywane lokalnie w przeglądarce. Nie ma kont, serwerowego salda, reklam ani wypłat. Punkty nie mają wartości pieniężnej. Prawdziwe nagrody lub wypłaty wymagają osobnego backendu, zabezpieczeń, regulaminów, polityki prywatności i zweryfikowanego źródła finansowania.
